# Required research material

- Team-approved scope, responsibilities and permission to describe unpublished work.
- Dataset source URL, terms, acquisition protocol, participant grouping and label definition.
- Original baseline/training/evaluation code with a reproducible environment.
- Aggregate figures from a held-out evaluation; no identifiable images or patient records.
- Bibliographic metadata for selected papers; link to publisher pages instead of copying PDFs.

Do not publish the current literature PDFs or private medical images as portfolio assets.
